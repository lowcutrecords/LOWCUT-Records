LOWCUT// RECORDS WEBSITE

HOW TO PUBLISH WITH GITHUB PAGES
1. Create a GitHub account.
2. Create a public repository named: YOURUSERNAME.github.io
3. Upload EVERYTHING inside this folder (index.html, styles.css, script.js and the assets folder).
4. Open Settings > Pages.
5. Under Build and deployment choose: Deploy from a branch.
6. Branch: main / root.
7. Save. GitHub will give you the website URL.

IMPORTANT BEFORE PUBLISHING
- Replace the placeholder social links in index.html.
- Replace lowcutrecords@example.com with the real LOWCUT// email.
- The demo form is visual only. The button currently copies a demo email template.
- You can later connect Formspree, Basin or another form service without changing the design.

FILES
index.html = website content
styles.css = full visual design
script.js = mobile menu + demo button
assets/ = LOWCUT logos, artist posters and release artwork
